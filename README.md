## 開發與圖片準則
原生 ES Modules、CSS、PWA，部署於 GitHub Pages。`data.js` 管理行程、交通及商場資料，`media.js` 管理圖片清單。`app.js` 負責互動，`styles.css` 負責排版。

使用者提供的購物參考照片只用於私下辨識，**不可放在公開程式庫、網站，也不可作為圖片載入失敗時的備用圖**。品牌商品照只使用對應正確品項與規格的正式圖片；未確認時顯示中性圖塊，不得放相似商品。

景點與商場照片應對應實際地點，並檢查可公開使用條件。相關維護資訊不出現在旅客網站頁面。購物勾選保存在瀏覽器本機。
