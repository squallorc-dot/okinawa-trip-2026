# 沖繩，慢慢走。｜2026 沖繩之旅

網站：https://squallorc-dot.github.io/okinawa-trip-2026/

## 五個分頁
總覽、行程、交通、必買、資訊。2026/11/11–11/16 六天五夜，供手機與桌機使用。

## 開發與圖片準則
原生 ES Modules、CSS、PWA，部署於 GitHub Pages。`data.js` 管理行程、交通及商場資料，`media.js` 管理圖片清單。`app.js` 負責互動，`styles.css` 負責排版。

使用者提供的購物參考照片只用於私下辨識，**不可放在公開程式庫、網站，也不可作為圖片載入失敗時的備用圖**。品牌商品照只使用對應正確品項與規格的正式圖片；未確認時顯示中性圖塊，不得放相似商品。

景點與商場照片應對應實際地點，並檢查可公開使用條件。相關維護資訊不出現在旅客網站頁面。購物勾選保存在瀏覽器本機。

## 圖片效能與儲存（2026-11-05）
- 已將授權可重新使用的沖繩景點與商場照片存放於 `assets/photos/*.webp`；原圖授權與作者紀錄見 `assets/photos/credits.json`。
- 品牌商品照片仍連結經查核的官方／正式商品零售圖片來源；若無公開再利用許可，**不**直接複製到公開 Repository。
- Service Worker 在旅客瀏覽過商品照後，會把該圖片快取於使用者自己的瀏覽器；已瀏覽過的商品照片在離線環境可能繼續顯示，但首次載入仍需網路。
- 嚴禁將使用者提供的原始購物辨識截圖重新上傳或復原到公開網站。
- 桌機字體依東京 12 月版參照 `Inter` + `Noto Sans TC`，桌機閱讀比例約 1.10–1.14；手機版沿用原排版。
